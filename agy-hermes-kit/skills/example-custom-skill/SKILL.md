# Example custom skill

Kad se zadatak poklapa sa opisom iznad:

1. Prikazi strukturu repozitorijuma (do 2 nivoa dubine).
2. Procitaj README i izvuci: namenu, komande za pokretanje, zavisnosti.
3. Vrati rezultat kao kratku listu, bez izmisljanja: ako podatak ne postoji, napisi "nije pronadjeno".
